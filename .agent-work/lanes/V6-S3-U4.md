Plan: `STAGE3_PLAN.md` §3 U4 (not committed), `docs/MASTER_PLAN_V6.md` §4 (`post`, `verify_post`, `get_context`). Migration: no. New env vars: none. New screen: none (a Board screen comes later from Designer).

## Owns
- new `hq/board-notes.ts`: note types, input rules, secret scrub, scopes (shared / project / mission), ranking and compact caps, the three tool bodies, the owner JSON view, and the HQ chat answer.
- `hq/connector.ts`: the `post` / `verify_post` / `get_context` branches only call `hq/board-notes.ts`; tool descriptions for those three.

- `kernel/types.ts`, `kernel/board.ts`, `kernel/schemas.ts`, `kernel/contracts.ts`: add the `shortcut` post type and let `verifyFinding` verify shortcuts; regenerate `supabase/functions/_shared/kernel.js`.
- hooks only: `hq/classify.ts` + `hq/chat.ts` (a "board" ask, DB-only, no model), `hq/server.ts` (`getBoardNotes`, chat wiring), `app/api/board/route.ts` (`GET ?view=notes`), `app/generated/hq.d.ts`.
- tests: `tests/unit/board-rules.test.ts`, `tests/unit/board-server.test.ts`, `tests/integration/board-posts.test.ts`.
