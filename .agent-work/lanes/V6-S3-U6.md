# V6 Stage 3 unit 6: daily self-tests + watchdog (no 6b backups)

- **Owns**: new `hq/selftest.ts` (checks, daily idempotent run, chat answer, health body), thin hooks in `hq/server.ts` (`postTick` daily hook, `getSelftestView`, `getTickHealth`), `app/api/tick-now/route.ts` GET, `app/api/board/route.ts` `?view=selftest`, `hq/classify.ts` + `hq/chat.ts` (selftest question), `ops/watchdog.workflow.yml` + `ops/WATCHDOG.md` (owner moves it into `dexter-workers`), tests `tests/unit/selftest.test.ts`, `tests/unit/selftest-server.test.ts`.
- **Out of scope**: U6b backups/restore (owner actions), pin/held-version checks that need U2 (`hq/pins.ts`), Cursor `/v1/me` live call (covered as a soft check when `CURSOR_API_KEY` is set; missing key is a soft fail, not a network call in the unit suite), migrations, live data, `.github/workflows` (box token has no `workflow` scope).
- **Done-command**: `env -u SUPABASE_DB_URL -u SUPABASE_URL -u SUPABASE_SERVICE_ROLE_KEY -u DATABASE_URL PGUSER=ubuntu sh -c 'npm run typecheck && npm run lint && npm test && npm run check:vendor && npm run check:briefs && npm run check:bundle && npm run scan:secrets && npm run test:integration'`
- **Design**: the existing per-minute tick (`POST /api/tick-now` with `DEXTER_TICK_SECRET`) runs `runDailySelftest` once per America/Tijuana calendar day under an advisory lock / in-memory guard. Results land as one `self_test` event (never secrets). Failures also write one `alert` post and one pending `selftest_alert` approval so Needs you lights up. Owner reads `GET /api/board?view=selftest` or asks chat "self test". Watchdog calls `GET /api/tick-now` with the same tick secret and fails when `tickAgeSeconds` is over 10 minutes.
