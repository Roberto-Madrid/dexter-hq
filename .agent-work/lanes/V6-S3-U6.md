# V6 / Stage 3 unit 6 — daily self-tests + watchdog

Branch: `v6/S3-U6-selftests` off `origin/main` (d0f7e89+).

## Design (actual)

- **Daily self-test** runs from `postTick` (existing `/api/tick-now` + pg_cron path), first tick on/after 07:00 America/Tijuana, once per calendar day via advisory lock + `events` (`action=self_test`, `target=self_test:<day>`). No migration.
- **Checks** (`SELFTEST_CHECKS`): database, connector_whoami, stop_state (>1 control row flagged), caps, stuck_reserving (>15m), long_running_agents (>6h), tick_fresh, tick_gaps, checker_credential (names only), role_sheet.
- **Needs you**: one pending approval per failed day (`id=alertApprovalId(day)`, action `pending:self_test_failed`).
- **Chat**: `postChat` short-circuits `isSelftestQuestion` → `selftestChatAnswer` (status kind). No classify/chat changes (avoids U4/U5).
- **Board**: `GET /api/board?view=selftest` → `{ latest, stale }` (owner cookie).
- **Watchdog**: separate `DEXTER_WATCHDOG_SECRET` (constant-time compare via sha256 + timingSafeEqual). `GET /api/tick-now` with `x-dexter-watchdog` → `selftestHealth`. Workflow YAML at `ops/watchdog.workflow.yml` (box token lacks `workflow` scope) — owner moves it.
