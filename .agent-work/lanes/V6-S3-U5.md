# Lane V6-S3-U5: weekly fleet report

Plan: `STAGE3_PLAN.md` §3 U5 (not committed), `docs/MASTER_PLAN_V6.md` §9 Stage 3. Migration: no. New env vars: none. New UI: none.

## Owns
- new `hq/fleet-report.ts` (pure aggregation, PT week math, idempotent weekly write, chat and board readers, memory store)
- new `hq/fleet-report-pg.ts` (windowed event read; one transaction: insert the post `on conflict do nothing`, append the event only when the insert won)
- hooks only: `hq/classify.ts` ("fleet report" kind), `hq/chat.ts` (DB-only answer), `hq/deps.ts` (`fleetReports?`), `hq/server.ts` (`postTick` hook, `getFleetView`, chat wiring), `app/api/board/route.ts` (`?view=fleet`), `app/generated/hq.d.ts`
- tests: `tests/unit/fleet-report.test.ts`, `tests/unit/fleet-report-server.test.ts`, `tests/integration/fleet-report.test.ts`

## Out of scope
- connector handlers (`hq/connector.ts`), caps (PR #28), venture endpoints (PR #29), any new screen, any new Vercel cron, migrations, live data.

## Storage (reuses existing tables)
- One `posts` row per PT ISO week: type `alert`, author `hq`, id = deterministic uuid from the week key, `evidence = {kind:"fleet_report", week, scope:"shared", body, repo:null, report}`.
- One `events` row `fleet_report` (actor `hq`, target = week key), written in the same transaction and only when the post insert won.

## Trigger
- `POST /api/tick-now` (existing per-minute `spike-tick`). The due week is the PT week (Mon 00:00 to Mon 00:00, America/Tijuana) that ended most recently, once it is Monday 07:00 PT or later.
