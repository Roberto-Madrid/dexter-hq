# Principles

For makers and the CEO. Load this file only when the task needs it.

- Do not wait on the owner for work that can be undone.
- Make an operation safe to repeat: a second run must not repeat an external effect.
- Prove it with fresh output. A claim without output is not done.
- Guard the context window: bring only the checklist and the code the task needs.
- Remove a moving part before adding one.
